### NextNEOpi Batch Execution

The 80 TCGA-BRCA patients were divided into **16 batches of five patients** for NextNEOpi processing on ASU SOL. The files `run_batch.slurm`, `batch_input.csv`, and `patients.txt` represent Batch 1. The remaining 15 batches followed the same execution setup, with batch-specific patient inputs.
